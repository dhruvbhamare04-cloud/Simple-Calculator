## 🚀 How to Run

1. Download or clone this repository.
2. Open the project in a C++ editor such as VS Code.
3. Save the program as `calculator.cpp`.
4. Compile and run the program.

Using a C++ compiler such as g++:

```bash
g++ calculator.cpp -o calculator
```

Run the program:

```bash
./calculator
```

On Windows, you can run:

```bash
calculator.exe
```

## 📌 Note

- Enter a non-zero second number when choosing division or remainder.
- Division uses integer values, so decimal results are not displayed.

## 🎯 Purpose

This project was created as a beginner C++ programming practice project to understand how `switch case` works and how to perform basic mathematical operations.
